# Problems regarding caching

Cache is never the original source of data, it is copy of the original data.

- **Cache Invalidation**
	Original Source (DB) and the copy (cache) may get out of sync.
- **Cache Eviction**
	- Original Source: DB: HDD
	- Copy: Cache: RAM
	- Space/Cost (HDD) >>> Space/Cost (RAM)
	- Cache may get full, therefore to store a new entry we need to remove existing entry.
