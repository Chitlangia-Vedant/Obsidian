Caching: Storing/Precomputing data at some place so as to not fetch it again and again from original source & thus to overall improve the performance of my application.
# Types of Caching
## In Browser Caching
### DNS values
Store the DNS values in local storage.
So we don't have to frequently access DNS server
### Images (static files/images)
Store images/files in local storage
