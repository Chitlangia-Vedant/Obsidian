# Functional Requirements
1. Restaurant system
	1. Add Restaurant with location
	2. Menu System (Skip)
2. Delivery system
	1. driver matching
	2. delivery tracking
3. Ordering and payment
# Non Functional Requirement
1. Availability for Restaurant and delivery tracking
2. Consistency for diver matching, Ordering and Payment

# API endpoint
- addRestaurant(name,location) 
- `searchRestaurent(location) -> list<restaurant> `
	- From nearest to farthest
	- Top 50
	- Pagation
- OrderFood(restaurant_id,food_id)
	- Payment(order_id)
	- DriverMatching(order_id)
- Delivery Tracking(order_id)
