# Step 4: Deep Dive

## Winning Strategy

`check()` -> We will need to check winner after every move
### Approach 1 (Row check)

```
for all player p:
	for every row r:
		bool check=true;
		for every cell c:
			if(board[r][c]!=p.symbol)
				check=false;
	if (check)
		winner=p;
```

Time Complexity: O($N^3$)
### Approach 2 (Row check)

After Player p's move -> Only Player p can win

```
for every row r:
	bool check=true;
	for every cell c:
		if(board[r][c]!=p.symbol)
			check=false;
if (check)
	winner=p; 
```

Time Complexity: O($N^2$)

### Approach 3 (Row check)

After Player p's move at the cell(r,c) -> Only Row r can have win

```
bool check=true;
	for every cell c:
		if(board[r][c]!=p.symbol)
			check=false;
if (check)
	winner=p; 
```

Time Complexity: O(N)

### Approach 4 

Keep the record of count of each player's symbol in each row

```
Map<pair<row_no,player>,int> rowMap;
```

After Player p's move at cell(r,c) 

```
if(++rowMap[{r,p}]==n); //n=size of board
	winner=p;
```

Time Complexity: O(1)
