When two things are related to each other, how many of the one thing is related to how many of other.

Types
- One to One (1-1)
- Many to One (M-1)
- Many to Many (M-M)

# How to represent cardinalities in table?

## 1-1
**Choose any of the table where you will keep the id the other**

| a_id | name | b_id |
| ---- | ---- | ---- |
| 1    | A    | 2    |
| 2    | B    | 1    |
| 3    | C    | 3    |

| a_id | name |
| ---- | ---- |
| 1    | X    |
| 2    | Y    |
| 3    | Z    |
## M-1
**Put id of the '1' side to 'M' side**
A<-M-1->B
