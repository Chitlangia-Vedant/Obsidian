# Step 0
## Overview
Design an entity which support write/draw behavior
## Entity
## No Persistence of Data
## Interaction with client: CLI

# Step 1
1. Any physical entity that can have write behavior 
2. Pen can either be closed via Cap or Click-Button
3. Supporting gel pen, ball pen or fountain pen
4. Gel & Ball pen will have a refil other won't have a refill
5. Refils will've Ink
	- Ink will have different colors
6. For every pen, we store 
	- Brand
	- Name
	- Price
	- Material
7. Often refils will've nibs
	- Nibs will have radius
	- Fountain pen will have its own nib
8. Methods
	- Pen should be able to write
	- We can open/close the pen
	- We should be able to refill the pens
# Step 2
- Class Diagram
- Identify the relationship
- Design pattern

```plantuml
@startuml

abstract class Pen{
	name
	brand
	price
	pt:PenType
	ct:CloseType
	{abstract} write()
	open()
	close()
}
enum PenType{
	BALL
	GEL
	FOUNTAIN
}
enum CloseType{
	CLICK
	CAP
	ROTATE
}
Interface(Refillable){
	refill()
}
class Ball{
	-refil: Refil
}
class Gel{
	-refil: Refil
}
class Fountain{
	-nib: Nib
	-ink: Ink
}
Pen<|--Gel
Pen<|--Ball
Pen<|--Fountain
class Refil{
	-nib: Nib
	-ink: Ink
}
class Nib{
	radius
}
class Ink{
	-color: String
	-density
	-List<InkFeatures> 
}
class InkFeatures{
	-Sparkling
	-Waterproof
	-Transparent
}
@enduml
```
