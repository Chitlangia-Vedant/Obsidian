# New Keyword
The new keyword is used to allocate memory at run time. All objects get memory in Heap memory area.
# Accessing data members within member functions

|                     | Static method | Non static method |
| :------------------ | :------------ | :---------------- |
| Non static variable | object        | direct            |
| Static variable     | direct        | direct            |
| Static method       | direct        | direct            |
| Non static method   | object        | direct            |
- Static members belong to the class (shared by all objects).
- Non-static members belong to individual objects (each object has its own copy).
- Static methods can access only static variables and methods directly.
- Non-static methods can access both static and non-static members

# Final
The final keyword in java is used to restrict the user. 
Final can be used with:
- Variable
- Method
- Class
